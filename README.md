# Monitoreo UPS

La idea del presente proyecto es simplificar la monitorizacion de todos los ups que se encuentran dentro del data center de la prosecretaria de informatica en pabellon argentina.

El proyecto se divide en dos partes importantes:

1. El primer bloque recolectara la informacion relacionada a la humedad del data center
2. El segundo bloque recolectara el estado de todos los ups disponibles.
